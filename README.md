

# 🛍️ Retail Customer Shopping Analysis

An end-to-end **Data Analytics project** analyzing **3,900 customer transactions** to uncover purchasing patterns, revenue drivers, product performance, and customer behavior.

## 📊 Key Metrics

- **3,900** customer records | **18** original attributes
- **$233K** approximate total revenue
- **$59.76** average purchase amount
- **3.75/5** average review rating
- **27%** subscribers vs. **73%** non-subscribers
- **37** missing review ratings handled during preprocessing
- **4** product categories and **4** customer age groups

## 🛠️ Tech Stack

**Python:** Pandas, NumPy, Matplotlib, Jupyter Notebook  
**SQL:** MySQL, CTEs, Subqueries, CASE, Aggregations, Window Functions  
**BI:** Power BI, KPI Cards, Slicers, Bar & Donut Charts

## 🔄 Analytics Workflow

`Data Collection → Data Cleaning → EDA → Feature Engineering → SQL Analysis → Power BI Dashboard → Business Insights`

### Key Analysis
- Cleaned and standardized **3,900 records**
- Imputed missing review ratings using **category-wise median**
- Created **4 age groups** and numerical purchase-frequency features
- Performed **10 SQL business analyses** covering revenue, products, discounts, shipping, subscriptions, and customer loyalty
- Developed an interactive Power BI dashboard for **customer, category, revenue, and demographic analysis**

## 📈 Key Findings

- **Clothing** generated the highest revenue at approximately **$104K**
- **Accessories:** ~$74K | **Footwear:** ~$36K | **Outerwear:** ~$19K
- Only **27% of customers are subscribers**, highlighting potential for subscription growth
- Customer revenue was analyzed across **4 age segments** to identify demographic patterns

## 🎯 Outcome

Built a complete **Python → MySQL → Power BI** analytics pipeline that transforms raw retail data into **actionable business insights** for customer segmentation, revenue analysis, and retail decision-making.
